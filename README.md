# TaskFlow — Modern To-Do & Task Manager

A modern, responsive, and aesthetically pleasing task management application built with pure Vanilla HTML5, CSS3, and JavaScript.

![TaskFlow App](https://img.shields.io/badge/status-active-success.svg)
![Vanilla JS](https://img.shields.io/badge/tech-HTML5%20%7C%20CSS3%20%7C%20JS-blueviolet)

---

## ✨ Features

- ✏️ **Task Editing**: Edit any task on the fly with the dedicated **Edit button** (pencil icon) or by double-clicking the task text. Update description and priority with keyboard shortcuts (`Enter` to save, `Esc` to cancel).
- 🎨 **Modern Design & Aesthetics**: Sleek glassmorphism card, ambient glow effects, vibrant gradients, and modern typography (*Plus Jakarta Sans*).
- 🌓 **Dark & Light Mode**: Seamless theme switcher that adapts to system settings or user preference and persists in `localStorage`.
- 📊 **Dynamic Progress Tracking**: Live animated progress bar showing percentage of completed tasks, ratio tracker, and motivational streak badges.
- 🎯 **Priority Management**: Color-coded priority badges (**Low**, **Medium**, **High**) for intuitive visual organization.
- 🔍 **Real-Time Search & Filtering**: Instant search bar with clear button and segmented filter tabs (**All**, **Active**, **Done**) with live badge counts.
- ↩️ **Undo Task Deletion**: Toast notification with a 1-click **Undo** action when removing a task.
- 🎉 **Celebration Confetti**: Pure Vanilla canvas particle explosion when reaching 100% completion.
- 📱 **Fully Responsive**: Tailored for mobile, tablet, and desktop screens with fluid layouts and accessible touch targets.
- 💾 **Offline & Persistent**: All tasks and preferences automatically save to your browser's `localStorage`.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No installation or build steps required!

```bash
# Optional: Serve locally with Python
python -m http.server 3000

# Or with Node
npx serve .
```

---

## ⌨️ Keyboard Shortcuts

- `Enter` in the main input to quickly add a task.
- `Enter` while editing a task to save changes.
- `Escape` while editing a task to cancel changes.
- `Double Click` on any task text to quickly start editing.
